# Wonderfall

> Animated desktop effects for Mac. Wonderfall is the new product and website name for the macOS app currently listed as {store_name} on the Mac App Store, app ID 6755106853, by Andrii (Andrew) Sereda.

## Available release
- Public listing checked: {checked_at}.
- Mac App Store name and version: {store_name} {version}.
- Requires macOS {minimum_os} or later; Mac only.
- Available effects: falling snow and custom PNG images. Up to 10 PNGs, each up to 5 MB and 1024 × 1024 pixels.
- Place the overlay over open windows or on the desktop behind them, while keeping the existing wallpaper.
- Controls include intensity, size, speed and wind.
- Current US store download price: {us_price}. Prices depend on the region and may change; the App Store is the source of current availability and pricing.
- The app is a desktop overlay, not a replacement for wallpaper or the macOS screensaver.

## Upcoming seasonal update
The videos and feature demos preview rain, autumn leaves, spring petals, summer fireflies, garlands and interactive clearing tools. These are not all included in the public {version} release. Optional weather matching uses location permission and Apple WeatherKit. The rain preview is visual and does not include ambient rain audio.
